# Video Minh họa Vận hành Agent Skill (Demo Video)

Dưới đây là đường dẫn video demo minh họa cách vận hành Agent Skill kiểm thử GUI, Usability và Cross-Platform tự động trên hệ thống EMS:

- **Đường dẫn Video Demo:** [Xem Video Demo Agent Skill (Google Drive)](https://drive.google.com/drive/folders/1hysq3WW5g3tUXwwlrnuPN44EZbLyCwAw?usp=sharing)
- **Các bước minh họa trong video:**
  1. Nạp Agent Skill `ems-gui-usability-testing-agent` vào AI Agent.
  2. Thực thi tự động kiểm thử GUI Checklist 45 mục (IA-01 đến IA-04) trên màn hình Form Support Request D1.
  3. Đánh giá tính tiện dụng theo 10 Nielsen Heuristics và xếp hạng Severity (0-4).
  4. Tự động tổng hợp và xuất Báo cáo Bug & Usability Findings Log chuẩn hóa.
